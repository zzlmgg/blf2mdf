# 03 — 解压失败、取消与越界收口

**What to build:** 测试工程师拖入损坏、加密、含路径穿越或嵌套包的 zip / rar / 7z 时，得到明确失败说明，解压内容不会写到解压根之外，也不会留下半截解压目录。解压或随后遍历途中取消，同样清掉这次未完成的解压根；已有镜像输出树不动。压缩包所在目录不可写时失败，不改解到其他位置。

**Blocked by:** 02 — rar 与 7z 走同一条来源

**Status:** ready-for-agent

- [ ] 损坏或无法识别的包失败，并给出用户能读的原因；不留下半截解压根
- [ ] 加密包失败，说明当前版本不支持加密压缩包；不弹密码框，不留下半截解压根
- [ ] 条目名含 `../` 或绝对路径时，解压根之外不出现被写出去的文件；该包失败或被拒绝
- [ ] 包内嵌套的 zip / rar / 7z 不再解开，也不当成 `.blf`
- [ ] 解压或遍历途中取消：抛出取消信号（界面按已取消处理，不按失败弹窗），未完成的解压根被删除；取消前已有的 `<主名>_t/` 仍在
- [ ] 父目录不可写时失败并说明原因，其他位置不出现解压根
- [ ] 解开后的目录里，无权限或被占用的子目录跳过并记日志，不中断其余候选
- [ ] 强制重解压在日志中留「已重新解压」，三种格式都成立
