# 同名文件夹避让 — 修改方案

Status: ready-for-agent
日期：2026-09-24
Feature slug: `archive-import`
取代：`spec.md` 里「每次强制重新解压 / 同名文件夹整目录删除后重建」。
不做：解压根里的标记文件 `.blf_dbc_extract`。

---

## 问题

现在拖入 `A02.zip` 时，解压根固定是旁边的 `A02`。这个目录只要存在，就会被整目录删除再解压。第一次拖入时旁边若已有同名文件夹（里面是另一份数据），那些文件会被删掉。

## 方案

同名路径已经存在时，不删除、不覆盖。压缩包改解到同一目录下、带本地时间戳的新文件夹。zip、rar、7z 走同一条解压路径，三条一起改。

首选名仍然是压缩包主名（只去掉最后一个扩展名）：

| 磁盘上的情况 | 解压到 | 产物镜像树 |
|---|---|---|
| 没有 `A02` | `A02\` | `A02_t\` |
| 已有 `A02`（文件夹或同名文件） | `A02_20260924_164105\` | `A02_20260924_164105_t\` |
| 上面这个时间戳名也已存在 | `A02_20260924_164105_2\`，仍占用则 `_3`、`_4`… | 与解压目录同名加 `_t` |

时间戳格式：本地时间 `YYYYMMDD_HHMMSS`。新名字先确认磁盘上不存在，再创建。已存在的 `A02`、`A02.zip`、`A02_t\` 以及更早的时间戳解压目录都不动。

镜像输出树仍由「实际解压根」按文件夹来源计算：树根名 = 解压目录名 + `_t`，内层目录原名，MDF 文件名加 `_t`。首选名空闲时，落点和今天一样。

## 行为

1. 第一次拖入，旁边没有同名目录：解到 `<主名>\`，产物在 `<主名>_t\`。
2. 第一次拖入，旁边已有同名文件夹或同名文件：不碰它，解到 `<主名>_<时间戳>\`。候选只来自新目录。
3. 再次拖入同一个压缩包，上次的 `<主名>\` 还在：再新建一个时间戳目录，上次解开的目录留在原地。
4. 同一次拖入既有压缩包、又有已存在的同名文件夹：文件夹按文件夹来源读，压缩包按上表避让后读。两套候选各算各的，文件夹内容不被删除。
5. 解压失败或取消：只删除这次新建的那个解压目录。避让前就已经存在的同名目录、压缩包、已有产物树不删。
6. 父目录不可写、加密包、损坏包、路径穿越：仍按现有失败语义，不把避让当成失败。
7. 界面不新增确认框。解压文案仍是「正在解压 `<压缩包文件名>`」。日志在发生避让时记下实际解压目录；不再写「已重新解压」（那句对应的是删除后重建）。

## 实现要点

- 选目录发生在解压之前，只改解压根的选择。解压后端（zip/rar 用系统 tar，7z 用 py7zr）、加密拒绝、穿越检查、取消清理的对象改成「这次创建的目录」。
- 去掉「目标已存在则 `rmtree`」这条路径。任何已存在路径都不是本次的删除对象。
- 「同一次拖入跳过解压根」只跳过本次真正要创建的那个新目录，避免去扫一个还不存在或即将写入的路径。已经存在、因而被避让开的同名文件夹不要跳过。
- 不写标记文件，不根据目录来历判断能不能删。

## 测试

来源解析接缝上改现有用例，并补避让用例。断言外部结果：哪些路径还在、候选的 BLF 与输出落在哪。

- 首选名空闲：仍解到 `<主名>\`，产物在 `<主名>_t\`。zip / rar / 7z 各保留一条。
- 同名文件夹已存在且内有其他文件：那些文件字节不变；新内容在时间戳目录；候选输出在对应的 `_t` 树；压缩包与已有 `<主名>_t\` 仍在。
- 同名文件（不是文件夹）已存在：不删除该文件，解到时间戳目录。
- 时间戳名也被占用：使用 `_2`，两个已存在的目录都保持原样。
- 同一次拖入压缩包和已存在的同名文件夹：文件夹里的文件还在，候选同时包含文件夹来源和这次解开的来源。
- 失败或取消：新建的时间戳目录被清掉，避让前的同名目录还在。
- 日志含实际解压目录，不含「已重新解压」。

界面拖拽接线不变：单个压缩包仍进解析，不走单个 `.blf` 加载。

## 不做

- 标记文件，以及「是我们解开的就可以删」。
- 弹窗询问是否覆盖。
- 自动清理上一次的时间戳解压目录或产物树。
- 不可写时改解到其他盘。
