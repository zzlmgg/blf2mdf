# 01 — core 来源解析与输出路径映射

**What to build:** 把用户拖入的路径集合解析成一份候选清单——每个候选带着三项已算定的信息：
BLF 路径、输出路径、相对显示名（外加大小）。文件夹来源递归找出其中全部 .blf（扩展名大小写
不敏感），同一条目重复出现只留一个，结果顺序确定；遇到无权限或被占用的目录跳过并在日志留痕，
而不是整次失败；一个 .blf 都没有时交出空清单。解析全程可上报进度、可响应取消。

**输出路径在解析期一次算定**，下游不再重算：散 .blf 落在它自己同目录、主名追加 `_t`；
文件夹来源落在与源**同级**的镜像树 `<源名>_t/`，树内目录沿用原名、只有 MDF 文件名追加 `_t`；
镜像树只复刻通向至少一个 .blf 的目录，空目录与无关文件不复制（但位于某 .blf 路径上的
中间目录要创建）。

**Blocked by:** None — 可立即开工

**Status:** ready-for-agent

- [ ] 拖入散 .blf（单个或多个）：每个候选的输出路径 = 各自同目录 + 主名 + `_t.mdf`
- [ ] 拖入文件夹：产物路径 = 同级 `<文件夹名>_t/` + 相对路径，树内目录保持原名、文件名追加 `_t`
- [ ] 源文件夹根下直接躺着的 .blf 也落在镜像树根（规则无例外）
- [ ] 镜像树落在源的同级，绝不落在源内部（不污染原始数据）
- [ ] 镜像树只复刻通向 .blf 的目录：空目录与无关文件不出现；位于 .blf 路径上的中间目录要创建
- [ ] 扩展名大小写不敏感（.blf / .BLF / .Blf 均命中）
- [ ] 同一条目重复出现（重复拖入 / 软链接）只产生一个候选
- [ ] 排序确定：同样的输入两次解析得到相同顺序
- [ ] 无权限或被占用的目录跳过并留日志，不中断整次解析
- [ ] 一个 .blf 都没有 → 交回空清单（界面层据此提示）
- [ ] 遍历期间可上报进度、可取消
- [ ] 模块无 Qt 依赖，可脱离界面直接单测
- [ ] CONTEXT.md 登记「镜像输出树」词条，并写明它与「输出路径与 BLF 同目录」是按来源类型
      分派的两条并行规则
