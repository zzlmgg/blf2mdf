# 01 — core 来源解析与输出路径映射

**What to build:** 把用户拖入的路径集合解析成一份候选清单——每个候选带着三项已算定的信息：
BLF 路径、输出路径、相对显示名（外加大小）。文件夹来源递归找出其中全部 .blf（扩展名大小写
不敏感），同一条目重复出现只留一个，结果顺序确定；遇到无权限或被占用的目录跳过并在日志留痕，
而不是整次失败；一个 .blf 都没有时交出空清单。解析全程可上报进度、可响应取消。

**输出路径在解析期一次算定**，下游不再重算：散 .blf 落在它自己同目录、主名追加 `_t`；
文件夹来源落在与源**同级**的镜像树 `<源名>_t/`，树内目录沿用原名、只有 MDF 文件名追加 `_t`；
镜像树只复刻通向至少一个 .blf 的目录，空目录与无关文件不复制（但位于某 .blf 路径上的
中间目录要创建）。

**Blocked by:** None — 可立即开工

**Status:** resolved (2026-09-23)
